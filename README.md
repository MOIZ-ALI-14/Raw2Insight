# 🧹➡️📊 Raw2Insight

### Turning messy café sales data into meaningful insights using Python, Pandas, and NumPy.

Raw2Insight is a practical **data cleaning and exploratory data analysis (EDA)** project built on a large, intentionally messy dataset containing **10,000 transactions and 8 columns**.

The project follows the complete journey:

**Raw Data → Cleaning → Validation → Analysis → Insights**

---

## 📊 Dataset

**10,000 rows × 8 columns**

| Column | Description |
|---|---|
| 🆔 Transaction ID | Transaction identifier |
| 🍽️ Item | Product purchased |
| 🔢 Quantity | Units purchased |
| 💵 Price Per Unit | Unit price |
| 💰 Total Spent | Transaction amount |
| 💳 Payment Method | Payment method |
| 📍 Location | Transaction location |
| 📅 Transaction Date | Transaction date |

---

## 🧹 Data Cleaning

The raw dataset contained missing values, invalid entries, inconsistent dates, and incorrect numerical data.

I worked on:

- 🔎 Data inspection and type conversion
- ❌ Invalid `ERROR` / `UNKNOWN` values
- 🔢 Missing numerical values
- 💵 Product-price correction
- 🏷️ Missing and ambiguous item values
- 💳 Missing payment methods
- 📍 Missing locations
- 📅 Invalid and inconsistent dates
- 🧪 Data validation and transaction checks

---

## 📈 Exploratory Data Analysis

After cleaning, I analyzed the dataset by:

- 💰 Overall sales
- 🍔 Item performance
- 🔢 Quantity sold
- 💳 Payment methods
- 📍 Locations
- 📅 Monthly transaction trends
- 🏆 Highest and lowest revenue days
